# Release and JED submission

Version 0.0.0 is an unreleased review candidate. Do not tag a production release
or submit this ZIP as approved until the outstanding checks are resolved.

1. Assign a company release operator and JED publisher; support is
   dev@mailchannels.com. Register at https://extensions.joomla.org/ and complete
   its email confirmation. Keep credentials in approved company storage.
2. Review supported contact templates/features, broader field types, site-side
   browser behavior and the actual deployment CAPTCHA. Validate administrator
   roles/session behavior relevant to the supported deployment. Recheck native
   lifecycle, partial-copy failure guidance and deliberate uninstall routing.
3. Perform explicitly authorized live-provider validation using approved sender
   and recipient identities. Never infer that a local fixture permits live sends.
4. Choose a real version and supported runtime range, review GPL/provenance,
   package metadata, documentation and update/distribution hosting. Build the ZIP,
   record hashes, install/reinstall/uninstall it on clean supported Joomla sites.
5. Publish an approved versioned source tag and direct ZIP download. Keep test
   fixtures and credentials out of the ZIP. Recheck source/download links.
6. Prepare screenshots and accurate contact-only description, service dependency,
   installation/support links and pricing classification. JED's SaaS rules require
   paid classification when the required service is paid or trial-only; “Free”
   requires a permanent free service tier. Verify the current plan; do not infer
   listing classification from the plugin's GPL license or zero code price.
7. In JED Profile > Submit extension, complete the form and record the pending
   receipt. Resolve review feedback; verify the accepted page, category/search
   discoverability and downloadable package. A source repository is not a listing.

Official requirements:
- https://extensions.joomla.org/support/knowledgebase/for-jed-developers/submitting-an-extension/
